# build stuff

i have a bunch of little bits and pieces i use to build software. here's a
loose grouping of them.

- [game](https://github.com/janearc/game) - used to build stuff in golang.
  extensive code quality and testing functionality. designed from the start to
  make coding with agents less scary.
- [dismay](https://github.com/janearc/dismay) - the other parts of building on
  a mac (c, objc, swift, xcode, etc). same goals as game.
- [pronghorn](https://github.com/janearc/pronghorn) - building a virtualized
  xnu environment for finding bugs in the apple ecosystem. it's not a
  red-teaming suite but if you wanted to use it that way i guess you could.

code quality

- [shuriken](https://github.com/janearc/libninja) - a go-specific code quality
  and linting tool
- [pzm](https://github.com/janearc/puzzlemouth) - a "standard lib" for my
  golang tooling, although i think anyone can benefit from using this.
- [readme](https://github.com/janearc/libreadme) - a library that verifies 
  low-vision users can actually read what is being output
- [okapi](https://github.com/janearc/okapi) - a comment editor, which replaces
  the kind of iffy comments that agents (particularly claude) tend to write.
